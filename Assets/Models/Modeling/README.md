# Modeling Folder Structure

- `_Incoming/Flowers`: raw/imported flower assets (including `FlowerV1` download)
- `_Incoming/Terrain`: terrain blocks and terrain meshes
- `_Incoming/Vegetation`: grass/tree raw assets
- `_Incoming/Props`: other props/packs from teammates
- `Textures/TerrainTiles`: shared terrain tile textures/atlases
- `_Exports`: exported deliverables

Rule: put new teammate drops into `_Incoming/<category>` first, then promote to runtime paths after validation.
